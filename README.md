# 拼多多券猎人 · 纯静默版

> **Hook 内部 API 直接领券，完全不占用屏幕，不影响前台操作**

## ✨ 核心优势

| 特性 | 说明 |
|------|------|
| **纯后台静默** | 不模拟点击、不操作界面、不占屏幕 |
| **刷抖音不影响** | 前台你玩你的，后台它领它的 |
| **无需无障碍** | 不需要开启无障碍服务 |
| **无需Root** | 配合 LSPatch 可免Root使用 |
| **全自动** | 注入后无需任何操作，自动轮询检测 |

## 📦 安装

### 方式一：LSPosed（推荐，需Root）
1. 安装 APK
2. LSPosed → 模块 → 启用「拼多多券猎人」
3. 勾选目标应用「拼多多」
4. 重启拼多多
5. 打开本 App 确认状态为「运行中」

### 方式二：LSPatch（免Root）
1. 安装 LSPatch
2. 用 LSPatch 修补拼多多 APK
3. 在 LSPatch 管理中启用本模块
4. 打开本 App 配置

## 🎯 工作原理

```
拼多多启动 → Xposed注入SilentCouponHunter
    ↓
Hook 7大入口：
├── ① 网络层拦截 — 拦截券API响应
├── ② 券管理器 — 直接调用领券方法
├── ③ 领券中心 — 数据加载时自动触发
├── ④ 商品页券 — 自动领取店铺/平台券
├── ⑤ 签到/任务 — 自动领取奖励
├── ⑥ 红包 — 自动开红包
└── ⑦ 定时轮询 — 每N秒主动刷新
    ↓
发现券 → 后台线程直接调用内部API领取
    ↓
统计更新 → 悬浮窗/App内显示
```

## ⚙️ 配置

| 配置 | 说明 | 默认 |
|------|------|------|
| 自动静默搞卷 | 总开关 | 开启 |
| 悬浮窗 | 显示统计面板 | 关闭 |
| 检测间隔 | 10~300秒 | 30秒 |
| 仅大额券 | 低于设定金额不领 | 关闭 |
| 最小券面额 | 如开启则仅领≥此金额 | 0元 |

## 🔄 与无障碍版对比

| 对比项 | 无障碍版（旧） | 纯静默版（本版） |
|--------|--------------|----------------|
| 操作方式 | 模拟点击 UI | Hook内部API |
| 前台影响 | 不能同时用手机 | 完全不受影响 |
| 无障碍权限 | 需要 | 不需要 |
| 稳定性 | 受UI变化影响 | 更稳定 |
| 速度 | 秒级操作 | 毫秒级API调用 |
